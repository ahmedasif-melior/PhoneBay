⚠️ IMPORTANT NOTES
═════════════════════════════════════════════════════════════════════════════

1. User Isolation:
   - Users cannot access other users' data
   - Middleware blocks cross-role access
   - API validates role on every request

2. Shop Verification:
   - Shops start in "pending" state
   - Admin must approve before full access
   - Status tracked in shop_profiles table

3. Admin Creation:
   - Only existing admins can create new admins
   - No web signup form for admin role
   - Use /api/admin/admins endpoint

4. User Blocking:
   - Blocked users can't access anything
   - Block reason is logged
   - Admins can unblock anytime

5. Audit Trail:
   - All admin actions logged
   - Includes who, what, when, and changes
   - Queryable by admin, entity, or time
